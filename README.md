A chess engine in 4,095 bytes of Python: iterative alpha-beta with quiescence, transposition and history ordering, mate-distance scoring, queen-aware king safety, and repetition handling that presses when ahead and accepts draws when defending. Deterministic on a fixed 50,000-node budget. Built by a recorded Codex session for make.fun's tiny-chess-01 bounty.

## Run it

```sh
MAKEFUN_ENV_URL=<env url> python3 main.py
```
